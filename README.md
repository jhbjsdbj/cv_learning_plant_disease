# 计算机视觉入门学习记录（植物保护方向）
我是华南农业大学植物保护专业学生，这是我的CV入门学习路径

---
## 学习内容&对应项目
### 1. 第一阶段：Numpy基础
- 掌握图像数组的核心概念：shape、RGB三通道、数组切片、批量像素运算、数值范围截断

### 2. 第二阶段：OpenCV图像预处理
- 完成真实叶片照片的灰度化、高斯去噪、边缘检测、轮廓提取
- 独立实现叶片从复杂背景中抠图的完整流程

### 3. 第三阶段：PyTorch玉米病害分类
- 数据集：PlantVillage公开数据集，选取三类玉米叶片（健康、普通锈病、北方叶枯病）
- 独立搭建2层简单CNN模型，加入随机翻转、旋转的数据增强
- 最终验证集准确率约98.7%，可输出训练损失/准确率曲线，能识别过拟合现象

---
## 项目说明
1.  数据集来源：PlantVillage公开数据集
2.  模型局限性：
    PlantVillage的图片均为实验室纯色背景拍摄，和田间真实复杂背景、带光影杂物的照片存在明显数据分布差异，模型在真实田间照片上的效果会出现下降，后续会针对田间数据做进一步优化。
